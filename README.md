# MintVCver1.0

| 序号 | 相对官方版的改进 | 简单说明 |
| --- | --- | --- |
| 1 | 界面更简单 | 音色弹窗选择，常用按钮留在主页，复杂选项收进高级设置。 |
| 2 | 设备选择更清楚 | 只显示 MME / WASAPI，输入、输出分别选择，并记住设置。 |
| 3 | 降噪和空间效果 | 增加本机 RNNoise 降噪和轻量房间混响，都可以开关。 |
| 4 | 声音处理 | 增加共享激励和可关闭的跨块相位连续，尝试减少声音接缝；不用 index、不重训，糊字仍可能出现。 |
| 5 | 运行优化 | 减少多余计算，修复消息积压导致的断连，增加引擎无响应提示，打开设置不打断变声。 |
| 6 | 游戏优化 | 支持的 NVIDIA 游戏可设置 120 FPS 上限，停止变声后恢复；高级设置可关闭。 |
| 7 | 账号与音色授权 | 注册后是 free；加密音色按账号授权，管理员和 svip 可用全部已上架音色。只有管理员能管理用户权限。 |
| 8 | 音色展示 | 可以查看允允音色、打开夸克下载；试听稍后添加。 |
| 9 | 软件更新 | 高级设置检查新版，从夸克下载；后续兼容版本支持校验后安装小补丁。 |

新版 v1.2.0：先注册或登录，再进入客户端。内置加密的允允音色，使用前需要授权；普通 .pth 仍可自行载入。声音处理在自己电脑上完成，服务器只负责账号和授权。
