# 萌妹AI变声（MintVC） · 2.1

[GitHub 下载](https://github.com/ysuhao/MintVC/releases/tag/v2.1.0) · [夸克下载](https://pan.quark.cn/s/9e190dd72dfb)

完整解压到新文件夹，双击 MintVC.exe，注册或登录后使用。无需安装 Python。

主页右上方「音色展示」提供 Myntheon系列、三角洲行动系列、明日方舟系列、碧蓝航线系列、无畏契约系列及花泽香菜。游戏合集标记为「免费游戏音色」，使用简洁的浅灰蓝卡片；Myntheon 保留深紫金色卡片和 Made by Mint 签名。

本版共展示 100 个音色：Myntheon 12 个、三角洲行动 2 个、明日方舟 39 个、碧蓝航线 30 个、无畏契约 16 个，以及花泽香菜。三角洲当前收录德穆兰和赛伊德；其他干员尚未收录。上架音色均为 .mintpth 加密格式。

免费游戏音色和花泽香菜供 free / VIP / SVIP / 管理员使用，Myntheon系列供 SVIP / 管理员使用。公开运行包不附带音色模型：点击音色「下载」打开夸克，下载后用「添加音色」导入。游戏角色使用中文名称和现成角色头像。

支持 MME / WASAPI、本机降噪和空间效果、托盘、快捷键、记住登录和软件更新。普通 .pth 仍可自行载入，受保护音色需要联网登录和持续授权。只有管理员能管理用户权限。声音在本机处理，服务器负责账号和授权。

Windows 10/11 x64，NVIDIA CUDA 11.8。请保留旧目录，下载运行包而非 Source code.zip。校验见 SHA256SUMS.txt，第三方许可见包内 notices。
