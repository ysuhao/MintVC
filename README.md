Aria、Lyra、Vesper 收入 **Myntheon系列**，署名 *Made by Mint*。公开运行包不附带音色模型：主页右上方进入音色展示，点击合集查看三款音色，再点击对应的「下载」打开夸克，下载后用「添加音色」导入。

支持 MME / WASAPI、可关闭的本机降噪和房间混响、托盘与快捷键、记住登录和软件更新。普通 .pth 仍可自行载入，受保护音色需要联网登录和持续授权。只有管理员能管理用户权限。

声音处理在自己电脑上完成，服务器只负责账号和授权。兼容的 NVIDIA 显卡使用 CUDA 11.8；其他硬件请以实机表现为准。试听音频待添加。
